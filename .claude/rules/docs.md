---
description: When and which docs to update after business logic changes
---

When business logic changes, update the relevant doc in `docs/`:

- Conversation states or transitions → `conversation-engine.md`
- Firestore schema → `data-model.md`
- Payment or webhook → `payment.md`
- WhatsApp senders or parsing → `whatsapp-integration.md`
- User flows → `user-flows.md`
